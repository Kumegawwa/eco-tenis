# Eco Tênis Academia — Premium Landing Page

Um projeto de arquitetura web e inteligência competitiva focado em alta conversão e posicionamento premium para academias de tênis. 

Este projeto não é um simples "site", mas uma máquina de Inbound Marketing desenvolvida para captar leads qualificados, agendar aulas experimentais e elevar a percepção de valor do clube.

## 🚀 Tecnologias Utilizadas
* **React 18** + **TypeScript**
* **Vite** (Build Tool super rápida)
* **TanStack Router** (Roteamento moderno e Type-Safe)
* **Tailwind CSS v4** (Estilização utilitária ágil)
* **Lucide React** (Ícones SVG otimizados)
* **Radix UI / Shadcn** (Componentes acessíveis: Accordion, Dialog, Avatar)

## 🎯 Destaques do Projeto
* **UX/UI Premium:** Design minimalista inspirado em clubes europeus, focado em "espaço negativo" e tipografia forte (Inter + Montserrat/Playfair).
* **Funil de Conversão (Lead Gen):** Modal nativo para pré-qualificação de alunos (nível de experiência, interesse), eliminando fricção de contato.
* **SEO Técnico:** Estrutura semântica, meta tags configuradas por rota, `robots.txt` e `sitemap.xml` prontos para rankeamento local (Curitiba/PR).
* **Omnichannel:** Botão "Sticky" global e integrado à API do WhatsApp.
* **Mapeamento:** Integração nativa de iframe do Google Maps com filtro visual em tons de cinza/contraste para manter a elegância da paleta.
